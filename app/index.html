Item database

Update downloads the item and blueprint lists from the Star Citizen Wiki and UEX (about 60 MB the first time). Nothing you track is sent anywhere.

Storage

Saved automatically
Daily backups, last 14 kept

Saved in this browser only. Clearing browser data erases it, so keep a backup.

Backups

Restoring saves a copy of your current data first.

Refresh on launch

Runs quietly in the background, and only if the data is more than 6 hours old. Mission and mining data are only refreshed once you have downloaded them the first time. Prices always refresh.

In-game overlay

A small box that stays on top of the game so you can add items without alt-tabbing. Works in Borderless or Windowed mode, not exclusive Fullscreen. Hold F in game to get the mouse, then click the box. Hotkey: Ctrl+Shift+O.

Import from Game.log

Reads the game's log file and lists items you looted, bought or moved. You tick what to add. Nothing is added on its own.

Experimental feature

    
Game.log import is experimental and is not 100% accurate. It reads container moves from the log, so it can miss items, count items you only moved, and get quantities wrong. Check the list before you add anything.
